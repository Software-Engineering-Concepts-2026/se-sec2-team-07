# Definition of Done (DoD)

งานจะถือว่าเสร็จสมบูรณ์ (Done) และพร้อมส่งมอบ เมื่อผ่านเกณฑ์ทั้งหมดดังต่อไปนี้:

1. โค้ดผ่าน Acceptance Criteria ครบทุกข้อตามที่ระบุใน Issue
2. โค้ดได้รับการทดสอบการทำงานเบื้องต้น (Manual Testing / Unit Test) และไม่มี Error
3. ทำการสร้าง Pull Request (PR) จาก feature branch เข้า main โดยไม่อนุญาตให้ push ตรง
4. ได้รับการ Code Review และอนุมัติ (Approved) จากสมาชิกในทีมอย่างน้อย 1 คน
5. มีการอัปเดตเอกสารที่เกี่ยวข้อง (เช่น API docs, README หรือ User Guide) หากมีการเปลี่ยนแปลง
6. โค้ดผ่านการ Merge เข้า main branch สำเร็จโดยไม่มีข้อขัดแย้ง (Merge Conflicts)
