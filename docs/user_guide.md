# คู่มือผู้ใช้ Focus Flashcards

อัปเดต: 10 ตุลาคม 2026 — อ้างอิงฟีเจอร์และข้อความในโปรเจกต์ปัจจุบัน

Focus Flashcards ใช้สร้างบัตรคำถาม–คำตอบ ทบทวนตามกำหนด จัดโน้ตและรายวิชา และดูความก้าวหน้าจากการทบทวนของคุณ
ใช้ผ่านเบราว์เซอร์บนคอมพิวเตอร์หรือโทรศัพท์ ไม่ต้องติดตั้งแอป
เปิดลิงก์ที่ผู้ดูแลแจ้ง เช่น [เว็บ Production](https://focus-flashcards.vercel.app/)
คู่มือนี้สำหรับผู้ใช้ ส่วนการติดตั้งและ deploy อยู่ใน [คู่มือพัฒนา](development.md) และ [คู่มือ Vercel](vercel.md)

## 1. เริ่มใช้งานครั้งแรก

1. เปิดเว็บ เลือกแท็บ **สมัครใหม่**
2. กรอกชื่อที่อยากให้เราเรียก อีเมล และรหัสผ่านอย่างน้อย 8 ตัวอักษร
3. กด **สร้างบัญชี** แล้วรอเข้าสู่หน้าภาพรวม
4. กด **สร้างชุดการ์ด** เลือก **เขียนเอง** แล้วกด **เพิ่มเอง**
5. กรอกคำถามด้านหน้าและคำตอบด้านหลัง ตั้งชื่อชุด แล้วกด **บันทึกชุดการ์ด**
6. เปิดชุดจากคลังและเลือกเริ่มทบทวน ลองนึกคำตอบก่อนพลิกการ์ด แล้วเลือกระดับความจำ

ตัวอย่างการ์ดแรก: ด้านหน้า `apple` ด้านหลัง `แอปเปิล`
เมื่อกลับมาใช้เว็บ เลือก **เข้าสู่ระบบ** แล้วกรอกอีเมลและรหัสผ่านเดิม ปุ่มรูปตาข้างรหัสผ่านใช้แสดงหรือซ่อนข้อความได้

## 2. เมนูและการออกจากระบบ

คอมพิวเตอร์มีเมนูด้านซ้าย โทรศัพท์มีเมนูด้านล่างและปุ่ม **เพิ่มเติม** สำหรับหน้าที่ไม่ได้แสดงโดยตรง

| หน้า           | ใช้ทำอะไร                                         | เส้นทางในเว็บ |
| -------------- | ------------------------------------------------- | ------------- |
| ภาพรวม         | ดูสรุปการเรียน ชุดการ์ดและภารกิจเริ่มต้น          | `#/`          |
| ชุดการ์ดของฉัน | เปิด สร้าง แก้ไข และเริ่มทบทวนชุด                 | `#/decks`     |
| ทบทวนการ์ด     | ทบทวนการ์ดที่ถึงกำหนดตามเวลาที่เหลือวันนี้        | `#/review`    |
| ตารางทบทวน     | ตั้งเวลารายวันและดูแผน                            | `#/schedule`  |
| Pomodoro       | จับเวลาช่วงเรียนและพัก                            | `#/pomodoro`  |
| โน้ต           | เขียนโน้ต อ่านข้อความจากไฟล์ และเก็บเอกสารต้นฉบับ | `#/notes`     |
| รายวิชา        | จัดกลุ่มการ์ดและโน้ตที่มีอยู่ในคลัง               | `#/courses`   |
| จัดเก็บการ์ด   | ทำเครื่องหมายเรียนจบหรือนำกลับมาทบทวน             | `#/archive`   |
| สถิติการเรียน  | ดูประวัติ ความแม่นยำ และหัวข้อที่ควรทบทวน         | `#/stats`     |
| ส่งออกผลงาน    | ดาวน์โหลดการ์ดและสรุปการเรียนรู้                  | `#/export`    |

ออกจากระบบบนคอมพิวเตอร์โดยกดไอคอนข้างข้อมูลบัญชีด้านล่างของ sidebar บนมือถือกด **เพิ่มเติม → ออกจากระบบ**
ถ้ามีร่างที่ยังไม่บันทึก ระบบจะให้ยืนยัน เลือก **ยกเลิก** เพื่อกลับไปบันทึกก่อน
เมื่อไม่ได้ใช้งานจน session หมดอายุ เว็บอาจให้เข้าสู่ระบบใหม่

## 3. สร้างชุดการ์ด

เปิด **ชุดการ์ดของฉัน → สร้างชุดการ์ด** หรือปุ่ม **สร้างชุดการ์ด** ในหน้าภาพรวม แล้วเลือกวิธีเริ่มต้น

### วางข้อความ

1. เลือก **วางข้อความ** แล้วใส่เนื้อหาที่ต้องการจำ
2. หากใช้โหมดแยกข้อความ ให้ใส่คำศัพท์และความหมายคนละบรรทัด เช่นตัวอย่างด้านล่าง
3. กด **สร้างการ์ดจากเนื้อหา** แล้วตรวจผล

```text
Stack: โครงสร้างข้อมูลแบบเข้าหลังออกก่อน
Queue: โครงสร้างข้อมูลแบบเข้าก่อนออกก่อน
```

### อัปโหลดไฟล์

1. เลือก **อัปโหลดไฟล์** แล้วเลือกไฟล์หรือลากไฟล์มาวาง
2. รอข้อความแจ้งสถานะ แล้วตรวจข้อความที่อ่านได้ในช่องด้านล่าง
3. แก้ข้อความผิดหรือจัดรูปแบบคำศัพท์ก่อนสร้างการ์ด
4. หากแสดงข้อความว่าใช้ OCR ให้ตรวจตัวอักษรและลำดับข้อมูล แล้วติ๊ก **ฉันตรวจและแก้ไขข้อความแล้ว** การแก้ข้อความอีกครั้งจะยกเลิกการยืนยันเดิม
5. กด **สร้างการ์ดจากเนื้อหา**

### เขียนเอง

เลือก **เขียนเอง → เพิ่มเอง** แล้วกรอกคำถามและคำตอบ กด **เพิ่มเอง** เพื่อเพิ่มใบถัดไป ไม่ต้องกรอกข้อความต้นทางหรือใช้ AI

### เลือกวิธีสร้างและใช้ AI

เปิด **ตัวเลือกการสร้าง** เพื่อเลือกวิธีสร้างและจำนวนการ์ดสูงสุด
**แยกข้อความ (ไม่ใช้ AI)** ใช้กฎแยกข้อความ ไม่ได้วิเคราะห์บทเรียนแบบ AI
**AI** ใช้ได้เมื่อผู้ดูแลตั้งค่าผู้ให้บริการแล้ว หากตัวเลือกถูกปิดยังใช้แยกข้อความหรือเขียนเองได้
ในโหมด AI สามารถเปิดตัวเลือกระดับความรู้และภาษาได้ เนื้อหาจะถูกส่งไปยังผู้ให้บริการที่ระบบตั้งค่าไว้เมื่อกดสร้าง
AI อาจสร้างได้น้อยกว่าจำนวนที่เลือกหรือให้คำตอบไม่ครบถ้วน จึงต้องตรวจและแก้ก่อนบันทึก

### ตรวจและบันทึก

1. ใช้ **เลือกการ์ดที่ต้องการแก้ไข**, **ก่อนหน้า** หรือ **ถัดไป** เพื่อสลับใบ หน้าสร้างใหม่แสดงทีละใบ โดยเก็บร่างของใบอื่นไว้
2. กรอกคำถามและคำตอบให้ครบ ลบใบที่ไม่ต้องการด้วยปุ่มถังขยะ หรือกด **คืนการ์ดที่ลบล่าสุด** หากลบผิด
3. กด **ไปขั้นตอนที่ 3 · ตั้งชื่อและบันทึก** เพื่อไปส่วนตั้งชื่อโดยไม่ต้องเลื่อนผ่านทุกใบ
4. ตั้ง **ชื่อชุดการ์ด** ปรับรายละเอียดเพิ่มเติมตามต้องการ แล้วกด **บันทึกชุดการ์ด**

ปุ่มบันทึกจะบันทึกทุกใบ รวมใบที่ไม่ได้แสดงอยู่ การกดสร้างเพิ่มจะเพิ่มการ์ดเข้าร่างเดิม
ร่างที่ยังไม่บันทึกไม่ได้ถูกเก็บเป็นชุดการ์ดในบัญชี

## 4. แก้ไขและลบชุดการ์ด

เปิดชื่อชุดจาก **ชุดการ์ดของฉัน** แก้ชื่อ รายละเอียด หรือคำถาม–คำตอบ แล้วกด **บันทึกชุดการ์ด**
หน้าชุดที่บันทึกแล้วเลือกแสดงทั้งหมดหรือเลือกแก้ทีละใบได้
หากเปลี่ยนหน้าขณะมีร่าง ระบบจะให้เลือกกลับไปบันทึกหรือยืนยันออกจากหน้า

กด **ลบชุดการ์ด** แล้วอ่านและยืนยันข้อความ การลบชุดจะลบการ์ดและประวัติที่เกี่ยวข้องด้วย
หากมีการ์ดเชื่อมรายวิชา ให้นำออกจากรายวิชาทั้งหมดก่อนลบต้นฉบับ
หากต้องการพักการ์ดจากการทบทวนแต่เก็บประวัติไว้ ให้ใช้ **จัดเก็บการ์ด** แทนการลบ

## 5. ทบทวนการ์ดและตั้งเวลารายวัน

เปิด **ตารางทบทวน** เลือกเวลา 5, 10, 15 หรือ 30 นาที หรือพิมพ์เองตั้งแต่ 1–120 นาที แล้วกด **บันทึกเวลาและปรับตาราง**
เวลานี้เป็นงบรวมของการทบทวนรายวัน ไม่ใช่เวลา Pomodoro

เปิด **ทบทวนการ์ด** เพื่อเริ่ม หรือเริ่มจากชุด/รายวิชาเพื่อกรองการ์ด ระบบยังเลือกเฉพาะใบที่ถึงกำหนดและพอดีกับเวลาที่เหลือวันนี้

1. อ่านคำถามและลองตอบในใจก่อน
2. คลิกการ์ดหรือ **พลิกดูคำตอบ**; บนคอมพิวเตอร์ใช้ Space ได้
3. หลังเห็นคำตอบ ให้ประเมินความจำตามความจริง:

| ระดับ    | เลือกเมื่อ                | ปุ่มลัดหลังพลิก |
| -------- | ------------------------- | --------------- |
| จำไม่ได้ | นึกคำตอบไม่ออกหรือตอบผิด  | `1`             |
| ยาก      | จำได้แต่ต้องใช้ความพยายาม | `2`             |
| จำได้    | ตอบได้ถูกต้อง             | `3`             |
| ง่าย     | ตอบได้อย่างคล่อง          | `4`             |

ผลที่บันทึกจะกำหนดรอบถัดไปตาม SRS และประวัติของการ์ด การกดพลิกอย่างเดียวไม่บันทึกผล
ใช้ **พักเวลา/เริ่มเวลาต่อ** ระหว่างพัก หรือ **จบรอบนี้** เพื่อจบก่อนครบ ผลที่บันทึกไปแล้วคงอยู่
เมื่อหมดเวลา ระบบจบรอบโดยไม่ตอบแทนคุณ

หากไม่มีการ์ดให้ทบทวน อาจยังไม่มีใบถึงกำหนด หรือเวลาที่เหลือไม่พอสำหรับอีกใบ ให้ดูตารางหรือกลับมาเมื่อถึงรอบถัดไป
การเริ่มทบทวนจากชุดหรือหัวข้อในสถิติไม่ข้ามกำหนด SRS

## 6. โน้ตและเอกสารต้นฉบับ

### สร้างและแก้โน้ต

1. เปิด **โน้ต** กรอก **ชื่อโน้ต** และ **เนื้อหาโน้ต** แล้วกด **บันทึกโน้ต**
2. ใช้ช่อง **อ่านข้อความจากไฟล์ PDF, PPTX, TXT หรือ Markdown** หากต้องการนำข้อความเข้าโน้ต รอผลแล้วตรวจและแก้ข้อความก่อนบันทึก
3. ค้นหาจากชื่อ/เนื้อหา หรือใช้ **ดูโน้ตที่บันทึก** เพื่อไปยังรายการ
4. กด **แก้ไขโน้ต** เพื่อแก้ต้นฉบับ หรือ **เริ่มโน้ตใหม่** เพื่อเริ่มร่างใหม่

ช่องอ่านข้อความเข้าโน้ตไม่เก็บไฟล์ต้นฉบับ และไม่ได้บันทึกโน้ตให้อัตโนมัติ
โน้ตที่เชื่อมรายวิชาจะมีผลกับทุกวิชาเมื่อแก้ไข และต้องนำออกจากวิชาที่เชื่อมก่อนลบต้นฉบับ

### เก็บเอกสารต้นฉบับ

ในหน้าเดียวกันมีส่วน **เอกสารต้นฉบับ**:

1. เลือกไฟล์ใน **เพิ่มเอกสารต้นฉบับ** แล้วรอรายการปรากฏ
2. กด **เปิดอ่านข้อความ** เพื่อดูข้อความที่สกัด หรือ **ดาวน์โหลดต้นฉบับ** เพื่อรับไฟล์เดิม
3. ใช้ **เปลี่ยนชื่อเอกสาร** หรือ **ลบเอกสาร** เมื่อต้องการจัดการรายการ

ส่วนนี้เก็บทั้งไฟล์และข้อความในบัญชี แต่ไม่ได้สร้างโน้ตหรือเชื่อมรายวิชาให้อัตโนมัติ
หากต้องการโน้ตจากเอกสาร ให้ใช้ช่องอ่านข้อความของโน้ตหรือคัดลอกข้อความไปสร้างโน้ตแล้วบันทึก
ข้อความที่สกัด โดยเฉพาะจากภาพสแกน อาจคลาดเคลื่อน ควรตรวจเนื้อหาเอง ส่วนเอกสารต้นฉบับไม่มีขั้นตอนยืนยัน OCR แบบหน้าสร้างการ์ด

## 7. รายวิชาและเนื้อหาที่ใช้ร่วมกัน

1. เปิด **รายวิชา** กรอก **ชื่อรายวิชาใหม่** แล้วกด **สร้างรายวิชา**
2. กด **เปิดรายวิชา → เพิ่มจากคลัง**
3. เลือกประเภท **การ์ด** หรือ **โน้ต** แล้วค้นหาเนื้อหาที่บันทึกไว้
4. กด **เชื่อมกับวิชานี้** สำหรับรายการเดียว หรือ **เชื่อมทั้งชุด** เพื่อเพิ่มการ์ดทุกใบในชุด โดยไม่เพิ่มใบที่เชื่อมอยู่ซ้ำ
5. ใช้ **ทบทวนวิชานี้** เพื่อเรียนการ์ดที่ถึงกำหนดของวิชานั้น

**สร้างโน้ตในคลัง** พาไปเขียนโน้ตใหม่ ส่วน **เพิ่มจากคลัง → โน้ต** ใช้เลือกโน้ตที่มีอยู่แล้ว
หากคลังไม่มีรายการ ให้บันทึกการ์ด/โน้ตก่อนกลับมาเชื่อม

การ์ดและโน้ตที่เชื่อมเป็นต้นฉบับเดียวกัน ไม่ใช่สำเนา กด **แก้ต้นฉบับ** ในรายวิชาเพื่อแก้ผ่าน popup แล้วอ่านข้อความยืนยันก่อนบันทึก
การแก้มีผลกับทุกวิชาที่เชื่อม การ์ดใบเดียวกันใช้ประวัติและรอบทบทวนร่วมกัน
**นำออกจากวิชา** เอาเฉพาะการเชื่อมออก การลบรายวิชาก็เก็บต้นฉบับการ์ด/โน้ตไว้

ใช้ **หยุดชั่วคราว/เริ่มต่อ** หรือ **รีเซ็ตช่วงนี้** ตามต้องการ เมื่อสลับช่วงให้กดเริ่มใหม่ และเมื่อครบช่วงระบบเตรียมช่วงถัดไปให้คุณกดเริ่มเอง

เปลี่ยนหน้าในแอปได้โดยเวลาเดินต่อ กล่องลอยบนหน้าอื่นแสดงเวลาปัจจุบัน
กดกากบาทเพื่อซ่อนกล่องโดยไม่รีเซ็ตเวลา แล้วกลับหน้า Pomodoro กด **แสดงกล่องเวลาบนหน้าอื่น** เพื่อแสดงอีกครั้ง
การรีเฟรช ปิดหน้า หรือออกจากระบบทำให้นาฬิกาเริ่มใหม่
ช่วงพักมีลิงก์ไปทบทวน Flashcards แต่การทบทวนยังใช้กำหนด SRS และเวลารายวันตามปกติ
เวลา Pomodoro ไม่นับเป็นสถิติการทบทวน

## 9. จัดเก็บและนำการ์ดกลับ

1. เปิด **จัดเก็บการ์ด → ยังทบทวนอยู่** แล้วค้นหาการ์ด
2. กด **เรียนจบแล้ว · จัดเก็บ** เพื่อเอาออกจากคิวทบทวน โดยเก็บต้นฉบับ ประวัติ และการเชื่อมรายวิชาไว้
3. เปิด **เรียนจบแล้ว** แล้วกด **นำกลับมาทบทวน** เมื่ออยากเรียนอีกครั้ง

คุณเป็นคนทำเครื่องหมายเรียนจบ ระบบไม่จัดเก็บจากคะแนนโดยอัตโนมัติ
การนำกลับไม่สร้างสำเนา และการเข้าคิวยังขึ้นกับเวลาทบทวนรายวัน

## 10. อ่านสถิติการเรียน

สถิติเริ่มมีข้อมูลหลังบันทึกผลทบทวนครั้งแรก หน้านี้แสดงจำนวนครั้ง การ์ดไม่ซ้ำ เวลาใช้ตอบ ระดับความจำ กิจกรรม 7 วัน และประวัติ
ความแม่นยำคำนวณจากจำนวนครั้งที่เลือก **จำได้/ง่าย** หารด้วยจำนวนครั้งทบทวนทั้งหมด ไม่ใช่คะแนนสอบ
การทบทวนใบเดิมหลายครั้งทำให้จำนวนครั้งเพิ่ม แต่ไม่ได้เพิ่มจำนวนการ์ดไม่ซ้ำ
วันในสถิติอ้างอิงเวลาไทย

หัวข้อคือชุดการ์ด ระบบแนะนำให้ทบทวนเพิ่มเมื่อมีอย่างน้อย 3 ครั้งและความแม่นยำต่ำกว่า 70%
ข้อมูลน้อยกว่านั้นยังไม่พอสำหรับคำแนะนำ ปุ่มทบทวนหัวข้อยังเคารพกำหนด SRS

## 11. ส่งออกผลงาน

1. เปิด **ส่งออกผลงาน** เลือกชุดที่ต้องการอย่างน้อย 1 ชุด สูงสุด 20 ชุดต่อไฟล์
2. เลือก **เนื้อหาแฟลชการ์ด**, **สรุปการเรียนรู้** หรือทั้งสองอย่าง
3. เลือก **HTML** สำหรับเปิดอ่านในเบราว์เซอร์ หรือ **JSON** สำหรับใช้ข้อมูลต่อ
4. ตรวจสรุปแล้วกด **ส่งออกไฟล์** และเปิดไฟล์ที่ดาวน์โหลด

ใช้ข้อมูลที่บันทึกแล้ว ณ เวลาส่งออก เฉพาะชุดที่เลือก ไม่เปลี่ยนต้นฉบับหรือตารางทบทวน
ไฟล์ที่ดาวน์โหลดส่งให้ผู้อื่นอ่านได้ จึงควรตรวจเนื้อหาที่เลือกก่อนแชร์
การส่งออก JSON ไม่ได้หมายความว่ามีเมนูนำเข้า JSON ในเว็บ

## 12. ข้อจำกัดและการแก้ปัญหา

| รายการ                    | ข้อจำกัดของแอป                                                          |
| ------------------------- | ----------------------------------------------------------------------- |
| ประเภทไฟล์                | PDF, PPTX, TXT, MD; ไฟล์อื่นให้คัดลอกข้อความหรือแปลงไฟล์ก่อน            |
| ไฟล์หนึ่งรายการ           | ไม่เกิน 20 MB; deployment อาจรับได้ต่ำกว่านี้ ให้แบ่งไฟล์เมื่อถูกปฏิเสธ |
| PDF                       | ไม่เกิน 100 หน้า; OCR ไม่เกิน 10 หน้าต่อไฟล์                            |
| ข้อความต้นทาง/เนื้อหาโน้ต | ไม่เกิน 60,000 ตัวอักษร                                                 |
| ชุดการ์ด                  | ไม่เกิน 500 ใบ; คำถามและคำตอบต้องไม่ว่าง                                |
| เวลาทบทวน                 | 1–120 นาทีต่อวัน                                                        |
| การส่งออก                 | สูงสุด 20 ชุดต่อไฟล์                                                    |

OCR อาจอ่านสระ วรรณยุกต์ IPA และตารางผิด การอ่านโมเดลภาษาครั้งแรกอาจใช้เวลานาน และไม่ได้รับประกันผลจากลายมือหรือทุกภาษา
เว็บต้องใช้อินเทอร์เน็ตเพื่อบันทึกและโหลดข้อมูล ยังไม่มีโหมดทำงานออฟไลน์

| สิ่งที่พบ                                        | ทำอย่างไร                                                                                                 |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| เปิดหน้าแรก/อ่านไฟล์ครั้งแรกนาน                  | รอข้อความสถานะ API หรือ OCR อาจกำลังเริ่มทำงาน หากขึ้น error ให้ใช้ปุ่มลองใหม่หรือแบ่งไฟล์                |
| เลือกไฟล์แล้วชื่อในช่องเลือกไฟล์หาย              | ดูข้อความสถานะและเนื้อหาที่อ่านได้ ช่องเลือกไฟล์ถูกล้างเพื่อให้เลือกไฟล์เดิมซ้ำได้ ไม่ได้แปลว่าบันทึกแล้ว |
| ไฟล์อ่านไม่ได้หรือ AI ล้มเหลว                    | ตรวจว่าร่างเดิมยังอยู่ เลือกไฟล์ใหม่ แบ่งไฟล์ วางข้อความ หรือเปลี่ยนเป็นเขียนเอง                          |
| AI ถูกปิด                                        | ใช้โหมดแยกข้อความ/เขียนเอง หรือแจ้งผู้ดูแลให้ตรวจการตั้งค่า AI                                            |
| บันทึกการ์ดไม่ได้                                | ตั้งชื่อชุดและกรอกคำถาม–คำตอบให้ครบทุกใบ รวมใบที่ไม่ได้แสดง                                               |
| ไม่พบการ์ดทบทวน                                  | ดูกำหนดและเวลาที่เหลือในตาราง อย่าสร้างสำเนาเพียงเพื่อให้เข้าคิวอีก                                       |
| สมัคร/ล็อกอินขึ้น “ไม่อนุญาตคำขอจากเว็บไซต์อื่น” | ใช้ลิงก์เว็บที่ผู้ดูแลแจ้ง แล้วแจ้ง URL และภาพ error ให้ผู้ดูแลตรวจโดเมน Production                       |
| เข้าสู่ระบบบ่อยเกินไป                            | หยุดลองและรอ 5 นาทีตามข้อความ แล้วตรวจข้อมูลก่อนลองใหม่                                                   |
| ลืมรหัสผ่าน                                      | ติดต่อผู้ดูแล ปัจจุบันไม่มีขั้นตอนรีเซ็ตรหัสผ่านทางอีเมลในหน้าเว็บ                                        |
| ข้อมูลถูกแก้จากอีกเครื่อง/บันทึกไม่แน่นอน        | อ่านข้อความแจ้งเตือน เก็บร่างไว้ และใช้ตัวเลือกลองใหม่หรือโหลดล่าสุดที่แสดง อย่ารีเฟรชเพื่อทิ้งร่างทันที  |
| ปุ่มลบต้นฉบับใช้ไม่ได้                           | เปิดรายวิชาที่เชื่อมแล้วนำเนื้อหาออกจากทุกวิชาก่อนลบ                                                      |

ร่างที่ยังไม่บันทึกอาจหายเมื่อรีเฟรช ปิดหน้า หรือยืนยันออกจากระบบ ควรบันทึกก่อนทำขั้นตอนเหล่านี้
หากยังมีปัญหา ส่งชื่อหน้า อุปกรณ์/เบราว์เซอร์ ขั้นตอนที่ทำ และภาพข้อความผิดพลาดให้ผู้ดูแล โดยไม่ส่งรหัสผ่าน
