1. What did you build?
   ผมกับทีมได้สร้าง Focus Flashcards เป็นเว็บช่วยเรียนและทบทวนความรู้ ผู้ใช้สร้างการ์ดเอง หรือใช้ AI สร้างจากข้อความและไฟล์ เช่น PDF ได้ นอกจากนี้ยังมีโน้ต รายวิชา ตารางทบทวน Pomodoro และสถิติการเรียน เพื่อให้จัดการเนื้อหาและติดตามการเรียนของตัวเองได้ในที่เดียวครับ
2. What problem did you solve?
   ปัญหาที่เราอยากแก้คือ เวลาเรียนมีเนื้อหาเยอะและกระจายอยู่หลายไฟล์ ทำให้เตรียมตัวทบทวนยาก การทำแฟลชการ์ดเองก็ใช้เวลา เราจึงทำระบบช่วยเปลี่ยนเนื้อหาเป็นการ์ด แล้วให้ผู้ใช้ตรวจและแก้ก่อนบันทึก รวมถึงจัดเนื้อหาเข้ารายวิชาและกลับมาทบทวนตามตาราง
3. What technical decision are you proudest of?
   ภูมิใจเรื่องการทดลองเปลี่ยน API มาใช้ Node.js บน Vercel ครับ เพราะหลัง deploy เราพบว่าเว็บรอโหลดนาน โดยเฉพาะการเปิดครั้งแรก จึงตรวจเวลาตอบกลับและทดลองปรับวิธีรัน backend ให้เหมาะกับแพลตฟอร์ม
4. What failure taught you the most?
   ตอน deploy แล้วสถานะขึ้น Ready แต่เปิดเว็บไม่ได้ สอนผมมากที่สุด เจอทั้งปัญหาไฟล์ที่ไม่ถูกนำไป build การเชื่อมต่อฐานข้อมูล และการล็อกอิน
5. What would you do differently?
   วางแผนเรื่อง deployment และ environment ตั้งแต่ต้น แล้วลอง deploy ระบบเล็ก ๆ ให้ทำงานก่อนค่อยเพิ่มฟีเจอร์
6. How did you embody Tip 52 (Delight Users)?
   พยายามดูว่าผู้ใช้ติดขัดตรงไหนระหว่างใช้งาน เช่น การแก้การ์ดหรือโน้ตแล้วต้องเปลี่ยนหน้า เราปรับให้แก้ผ่าน popup ได้สะดวกขึ้น และกล่อง Pomodoro ก็สามารถซ่อนได้โดยยังรักษาสถานะเวลาไว้
7. How did you embody Tip 53 (Sign Your Work)?
   พยายามทำให้งานตรวจสอบย้อนหลังได้ โดยใช้ commit ที่อธิบายการเปลี่ยนแปลง เขียนเอกสาร และเตรียม PR ให้คนอื่นเข้าใจเหตุผลของงาน แล้วงานส่วนไหนที่ใช้ Ai ต้องรับผิดชอบตามที่ทำแล้วไม่ยก credit ให้กับตนเอง สำหรับการรับผิดชอบงานหมายถึงต้องอธิบายได้ว่าทำอะไร ทดสอบอย่างไร และยังมีข้อจำกัดตรงไหน
8. What value did this experience add to your SE journey?
   โปรเจกต์นี้ทำให้เข้าใจกระบวนการพัฒนาระบบตั้งแต่ความต้องการของผู้ใช้ ไปจนถึงการทดสอบและ deploy ได้ฝึกอ่าน log แก้ปัญหา ใช้ Git และตัดสินใจจากหลักฐานมากขึ้น
