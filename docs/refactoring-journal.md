## Smell ที่เจอ : Duplicated Code (หรือ Long Method / Poor Naming)

ที่ไหน (File/Line): ระบุชื่อไฟล์และบรรทัดที่พบ เช่น prototypes/sprint1/Nattapon_upload_prototype.html (บริเวณโครงสร้างโค้ดซ้ำ ๆ หรือฟังก์ชันที่มีขนาดยาวเกินไป)

ทำไมจึงถือว่าเป็น smell: ละเมิดหลักการ DRY (Don't Repeat Yourself) ทำให้เมื่อต้องการแก้ไขดีไซน์หรือโค้ดส่วนกลาง ต้องตามไปแก้หลายจุดเสี่ยงต่อการเกิด Bug ตกหล่น และดูแลรักษายาก (Maintainability ต่ำ)

## Lesson

สิ่งที่เรียนรู้: การทำ Refactor ทีละนิดอย่างมีวินัย (Refactor Early, Refactor Often ตามปรัชญา Pragmatic Programmer) และการยึดหลัก Tests pass ก่อนลงมือแก้

AI Workflow ที่ใช้: ใช้ GenAI เป็น Co-pilot ตามแนวทาง Explain → Propose → Apply → Test โดยทีมต้องเป็นผู้ทำความเข้าใจและเขียนโค้ดเอง ไม่ปล่อยให้ AI ทำทั้งหมด
