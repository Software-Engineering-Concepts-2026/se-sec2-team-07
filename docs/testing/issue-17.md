# Issue #17 — แก้ไขแฟลชการ์ดที่บันทึกแล้ว

ตรวจเกณฑ์จาก [GitHub Issue #17](https://github.com/Software-Engineering-Concepts-2026/se-sec2-team-07/issues/17) วันที่ 1 ตุลาคม 2026: เลือกการ์ด แก้คำถาม/คำตอบ บันทึก แสดงข้อมูลล่าสุด และแจ้งเมื่อบันทึกไม่สำเร็จ

## ขอบเขตและการใช้งาน

เข้าคลังการ์ดแล้วเปิดชื่อชุดที่บันทึกไว้ เลือก **เลือกการ์ดที่ต้องการแก้ไข** เพื่อแสดงเฉพาะใบที่ต้องการ หรือเลือกแสดงทั้งหมด ค่าเริ่มต้นแสดงทั้งหมดเหมือนเดิม รายการใช้เลขการ์ดและคำถาม 80 ตัวอักษรแรกเพื่อระบุใบ รวมการ์ดที่เรียนจบแล้วด้วย

- การสลับตัวเลือกไม่ทิ้งร่าง และ **บันทึกชุดการ์ด** บันทึกการแก้ไขทุกใบ รวมใบที่ไม่ได้แสดง
- เมื่อคำถามหรือคำตอบว่าง ระบบแสดงการ์ดที่ผิดพร้อมแจ้งเลขใบ ไม่บันทึกข้อมูลบางส่วน
- เพิ่ม/ลบ/คืนการ์ดจะกลับมาแสดงทั้งหมด ป้องกันตัวเลือกชี้การ์ดที่ถูกลบ การโหลดชุดใหม่หรือข้อมูลล่าสุดล้างตัวเลือกเดิม
- ใช้ API บันทึกเดิมของ #4/#10: ตรวจเจ้าของ, revision conflict, transaction และ request_id สำหรับ retry เดิม ไม่เพิ่ม endpoint หรือ migration
- สำเร็จแล้วกลับคลัง เปิดชุดอีกครั้งเห็นข้อมูลล่าสุดที่บันทึกจากเซิร์ฟเวอร์
- ล้มเหลวแสดงข้อความและเก็บร่าง ถ้ายังไม่ทราบผลการบันทึกให้กดบันทึกอีกครั้งเพื่อยืนยันคำขอเดิมโดยไม่สร้างซ้ำ กรณีข้อมูลชนกันใช้การดึงข้อมูลล่าสุดโดยยืนยันแทนที่ร่าง
- การแก้ข้อความคง card ID, กำหนดทบทวน, จำนวนทบทวน, สถานะจัดเก็บ และการเชื่อมวิชา การ์ดร่วมวิชายังคงมีหน้าต่างยืนยันก่อนบันทึก

## เจ้าของไฟล์

root รับผิดชอบการตรวจเกณฑ์, `src/frontend/src/pages/Editor.jsx`, `tests/e2e/issue17.spec.js` และเอกสารครั้งนี้ ใช้ระบบ backend/database เดิมที่ตรวจแล้ว ไม่เปลี่ยนสถาปัตยกรรมหรือโครงสร้างฐานข้อมูล
