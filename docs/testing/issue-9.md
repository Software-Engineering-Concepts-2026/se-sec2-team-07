# Issue #9 — Pomodoro และการทบทวนช่วงพัก

เกณฑ์: https://github.com/Software-Engineering-Concepts-2026/se-sec2-team-07/issues/9

## พฤติกรรมที่กำหนด

- เมนู Pomodoro ใช้ช่วงเรียน 25 นาทีและช่วงพัก 5 นาที เริ่ม หยุดชั่วคราว เริ่มต่อ และรีเซ็ตช่วงปัจจุบันได้
- คำนวณเวลาจากเวลาสิ้นสุดจริง ไม่ลดทีละหนึ่งตามจำนวนครั้งที่ browser เรียก timer เพื่อรองรับการสลับแท็บหรือเครื่องพัก
- เมื่อช่วงเรียนจบ แจ้งเตือนในแอปและเตรียมช่วงพัก 5 นาที ผู้ใช้กดเริ่มเอง เมื่อพักจบแจ้งเตือนและเตรียมเรียนรอบใหม่ 25 นาที ไม่มีการเริ่มช่วงถัดไปเอง
- เมื่ออยู่ช่วงพักมีลิงก์เข้าสู่ Review โดยใช้บัญชีเดิม ไม่ออกจากระบบหรือเปลี่ยนหน้าให้เอง
- Timer อยู่ต่อเมื่อเปลี่ยนหน้าภายในแอป มีแถบแสดงเวลาและข้อความจบช่วงในหน้าอื่น จึงรับรู้ได้ขณะทบทวน
- Pomodoro แยกจากเวลาทบทวนรายวัน #6 ไม่เพิ่มเวลาที่ตอบการ์ด ไม่ลงคะแนนแทนผู้ใช้ ไม่เร่งกำหนดการ์ด และไม่เพิ่มสถิติการทบทวนเอง

## ข้อจำกัดที่ยังติดตาม

- Timer เก็บในหน่วยความจำของแท็บ โหลดหน้าใหม่ ปิดแท็บ หรือออกจากระบบจะเริ่มใหม่ ไม่ซิงค์ข้ามแท็บ/อุปกรณ์
- แจ้งเตือนเป็นข้อความในแอป ไม่มีเสียงหรือการแจ้งเตือนระบบปฏิบัติการ ขณะแท็บถูกพักจะประเมินเวลาที่ผ่านไปเมื่อ browser กลับมาประมวลผล ไม่รับรองการแจ้งตรงวินาทีขณะปิดแอป
- ใช้นาฬิกาของเครื่อง การเปลี่ยนเวลาเครื่องอาจมีผลกับเวลาที่เหลือ
- ยังไม่รองรับตั้งระยะเวลาเอง พักยาวทุกสี่รอบ หรือบันทึกประวัติรอบ Pomodoro
- การทดสอบเร่งเวลาจำลองใน Chrome ไม่ทดแทนการทดสอบ sleep/แบตเตอรี่บนมือถือจริง ข้อจำกัด AI/PDF/ข้อมูลขนาดใหญ่จากงานก่อนหน้ายังคงอยู่
