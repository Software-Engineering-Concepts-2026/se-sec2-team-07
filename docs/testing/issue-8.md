# Issue #8 — สร้างการ์ดตามระดับความรู้

เกณฑ์: https://github.com/Software-Engineering-Concepts-2026/se-sec2-team-07/issues/8

## พฤติกรรม

- ในหน้าสร้างชุดการ์ด เลือกวิธี AI แล้วเลือกระดับเริ่มต้น/กลาง/สูง ค่าเริ่มต้นคือกลาง สำหรับการสร้างครั้งนั้น ไม่ใช่ระดับประจำบัญชี
- เริ่มต้น: ถามข้อเท็จจริงเดียวที่ระบุชัด ใช้ภาษาง่าย ไม่ต้องอนุมาน
- กลาง: อธิบายหรือเปรียบเทียบความสัมพันธ์หนึ่งประเด็น ไม่ต้องใช้เหตุผลหลายขั้น
- สูง: วิเคราะห์หรือประยุกต์โดยเชื่อมหลายข้อเท็จจริงที่ระบุในเอกสาร หลีกเลี่ยงคำถามท่องจำอย่างเดียว
- ทุกระดับห้ามใช้ความรู้นอกเอกสาร กำหนดให้โมเดลตรวจความยากก่อนส่งคืนและลดจำนวนการ์ดเมื่อแหล่งข้อมูลไม่พอ ไม่แต่งข้อมูลเพื่อให้ครบจำนวน
- หากไม่มีการ์ดที่ส่งกลับ แจ้งให้เพิ่มเนื้อหาหรือเลือกระดับอื่นโดยรักษาร่างเดิม
- เปลี่ยนระดับไม่แก้การ์ดเดิม สร้างเพิ่มต่อท้ายร่าง ผู้ใช้ตรวจ/แก้/ลบก่อนบันทึกตาม #4 การสร้างล้มเหลวรักษาข้อความ ระดับที่เลือก และร่าง
- API รับ level เฉพาะ beginner/intermediate/advanced; ไม่ส่งใช้ intermediate ค่าผิดปฏิเสธก่อนเรียก AI
- โหมดแยกข้อความไม่ปรับระดับและไม่เรียก AI ไม่มีการเปลี่ยนโมเดล ราคา หรือส่งประวัติการเรียนไปยังบริการ AI

## หลักฐานและขอบเขตการยืนยัน

- `tests/unit/issue8.test.js`: ตรวจคำสั่งที่ส่งจริงผ่าน request จำลองทั้งสามระดับ ค่าเริ่มต้น ค่าผิด/ชื่อ property อันตราย ผลลัพธ์ว่าง และ local mode
- `tests/integration/api.test.js`: API ปฏิเสธ level ผิดและ local output ไม่เปลี่ยน ไม่มีชุดการ์ดบันทึกเอง
- `tests/e2e/issue8.spec.js`: เลือกระดับ สร้าง แก้ร่าง ล้มเหลว ลองใหม่ บันทึกและเปิดใหม่ บน desktop/mobile โดยจำลอง AI แต่ใช้ฐานข้อมูลจริง

## งานที่ยังต้องทดสอบจริง

- [ ] เรียกบริการ AI จริง ตรวจ key/model/quota และความเหมาะสมทั้งสามระดับกับเอกสารภาษาไทยจริง
- [ ] ให้ผู้เรียน/ผู้รีวิวประเมินว่าคำถามง่ายหรือยากเกินระดับหรือไม่ รวมกรณีเอกสารสั้นและคำสั่งแทรกในเอกสาร
- [ ] ยืนยันเกณฑ์ด้านคุณภาพเนื้อหา AC3 และ AC5 ก่อนถือว่า Issue ผ่านการยอมรับทั้งหมด: การทดสอบปัจจุบันยืนยันการส่งระดับและกติกา ไม่ได้พิสูจน์ว่าโมเดลทำตามเสมอ

Structured Outputs ควบคุมรูปแบบผลลัพธ์ ไม่ใช่การรับรองความเหมาะสมเชิงเนื้อหา จึงยังต้องตรวจร่างและทดสอบคุณภาพจริง อ้างอิง [OpenAI Docs](https://developers.openai.com/api/docs/guides/structured-outputs)

ยังไม่มีการอนุมานระดับอัตโนมัติจากสถิติหรือบันทึกระดับลงบัญชี ข้อจำกัดใน #3/#5/#7 รวม PDF timeout ภายใต้ภาระสูงยังคงติดตามต่อ

จุดก่อนเริ่มงาน `bb2519b` ไม่มี migration ใหม่ แยก commit ระบบ หน้าจอ และการทดสอบ
