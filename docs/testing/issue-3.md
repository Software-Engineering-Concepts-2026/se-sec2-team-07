# Issue #3 — สร้าง Flashcards จากเอกสาร

เกณฑ์: https://github.com/Software-Engineering-Concepts-2026/se-sec2-team-07/issues/3

## วิธีใช้งานและขอบเขต

1. เปิดสร้างชุดการ์ด เลือก PDF, PPTX, TXT หรือ MD หรือวางข้อความจากโน้ต
2. ตรวจข้อความที่อ่านได้ เลือกจำนวนการ์ดสูงสุดและวิธีสร้าง
3. โหมด AI ส่งข้อความไปยัง OpenAI เมื่อกดสร้างเท่านั้น ต้องตั้งค่า key และ model ฝั่งเซิร์ฟเวอร์ โหมดแยกข้อความใช้งานได้โดยไม่ใช้ AI
4. ตรวจแก้คำถามและคำตอบก่อนกดบันทึก ร่างไม่ถูกบันทึกอัตโนมัติ

จำกัดไฟล์ 20 MB, PDF 100 หน้า, ข้อความ 60,000 ตัวอักษร และ PPTX หลังคลาย 50 MB ไม่รองรับ OCR/ภาพสแกน, PPT รุ่นเก่า หรือข้อความในภาพและแผนภูมิ การอ่านใช้เวลาสูงสุด 20 วินาที ทำงานในโปรเซสแยกที่จำกัด JavaScript heap 256 MB เพื่อแยกผลกระทบหากตัวอ่าน PDF หยุดทำงาน

ไฟล์ผิดประเภท ไฟล์ว่าง ไฟล์เสีย และการสร้างล้มเหลวแสดงข้อผิดพลาด การอ่านไฟล์ใหม่ล้มเหลวไม่ลบข้อความและร่างเดิม สามารถเลือกไฟล์ใหม่หรือวางข้อความแล้วลองอีกครั้ง ร่างยังไม่รองรับการกู้คืนหลังปิดหรือโหลดหน้าใหม่

PPTX รักษาลำดับข้อความใน run และย่อหน้า รวมทั้งเลขที่มีศูนย์นำหน้าและ XML entities มาตรฐาน PDF ไม่เติมข้อความเลขหน้าที่ตัวอ่านสร้างขึ้นเอง เพื่อไม่ให้ไฟล์ไร้ข้อความถูกเข้าใจว่ามีเนื้อหา

## การตรวจสอบ

- `tests/unit/issue3-extraction.test.js`: อ่าน PDF จริง, PPTX หลาย run/ย่อหน้า, Markdown ภาษาไทย, ไฟล์เสีย/ว่าง/ไม่รองรับ และขนาดเกินกำหนด
- `tests/unit/issue3-generation.test.js`: ส่งข้อความต้นฉบับครบ กำหนดให้ใช้เฉพาะข้อเท็จจริงในเอกสาร จำกัดจำนวนผลลัพธ์ และแจ้งข้อผิดพลาดเมื่อ AI ตอบไม่ครบ/ปฏิเสธ/ผลไม่ถูกต้อง/หมดเวลา
- `tests/e2e/issue3.spec.js`: อัปโหลด TXT จริง สร้างร่าง รับมือไฟล์ผิดและ AI ล้มเหลว ลองใหม่ บันทึกและเปิดใหม่ บน desktop/mobile
