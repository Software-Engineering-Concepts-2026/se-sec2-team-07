# Project Proposal

## 1. Theme

**Theme: Education / Learning**

Focus Flashcards มุ่งเน้นการช่วยผู้เรียนเปลี่ยนเอกสารหรือโน้ตที่มีอยู่ให้กลายเป็น Digital Flashcards เพื่อใช้ในการทบทวนอย่างมีประสิทธิภาพ โดยนำ AI เข้ามาช่วยลดเวลาในการสร้างเนื้อหาสำหรับการเรียนรู้ นอกจากนี้ระบบยังสนับสนุน Active Recall และ Spaced Repetition ซึ่งช่วยให้ผู้ใช้สามารถทบทวนความรู้ได้อย่างเป็นระบบและต่อเนื่อง

## 2. Project Name

**Focus Flashcards**

## 3. Main Persona

**นิชา “นิ่ง” ศรีสุข นักศึกษาปี 2 สาขา Computer Science**

นิชาเป็นนักศึกษาที่ต้องเตรียมตัวสำหรับการสอบหลายวิชาและมีเวลาในการทบทวนจำกัด โดยเฉพาะวิชาที่มีเนื้อหาจำนวนมาก เช่น Data Structures และ Algorithms เธอคุ้นเคยกับการใช้เทคโนโลยีและ AI แต่ต้องการควบคุมและตรวจสอบเนื้อหาที่ AI สร้างขึ้นด้วยตนเองก่อนนำไปใช้เรียนจริง ดังนั้นเธอต้องการเครื่องมือที่สามารถเปลี่ยน Lecture Notes หรือเอกสารประกอบการเรียนให้เป็น Flashcards ได้อย่างรวดเร็ว พร้อมสามารถแก้ไข Flashcards และทบทวนตามช่วงเวลาที่เหมาะสมได้

## 4. Value Proposition

Focus Flashcards แก้ปัญหาการเสียเวลาในการสร้าง Flashcards ด้วยตนเองจาก Lecture Notes, Slides หรือเอกสารการเรียน โดยใช้ AI ช่วยสร้าง Flashcards จากเนื้อหาที่ผู้ใช้อัปโหลดและเปิดโอกาสให้ผู้ใช้ตรวจสอบหรือแก้ไขเนื้อหาได้ คุณค่าที่ผู้ใช้ได้รับคือสามารถเริ่มทบทวนได้เร็วขึ้น พร้อมระบบ Spaced Repetition และการติดตามสถิติการเรียนที่ช่วยให้การทบทวนมีประสิทธิภาพและต่อเนื่องมากขึ้น

## 5. MoSCoW Priorities

### Must Have

- **AI Flashcard Generation** สร้าง Flashcards จากเอกสารหรือโน้ตที่ผู้ใช้อัปโหลด
- **Flashcard Editor** ผู้ใช้สามารถตรวจสอบ แก้ไข และปรับปรุง Flashcards ที่ AI สร้างขึ้น
- **Flashcard Review** สามารถเปิดดูและตอบ Flashcards เพื่อทบทวนความรู้
- **User Authentication & Data Storage** ผู้ใช้สามารถเข้าสู่ระบบและจัดเก็บ Flashcards ของตนเองได้

### Should Have

- **Spaced Repetition** จัดลำดับและกำหนดช่วงเวลาการทบทวนตามผลการตอบของผู้ใช้
- **Statistics Dashboard** แสดงข้อมูล เช่น Accuracy, Study Time, Current Streak และ Progress

### Could Have

- **Achievements / Learning Streaks** เพิ่มระบบ Achievement และ Streak เพื่อสร้างแรงจูงใจในการเรียน
- **Accuracy Trend & Review Distribution** แสดงแนวโน้มความแม่นยำและการกระจายของการทบทวนในรูปแบบกราฟ

### Won’t Have (This Term)

- **Real-time Collaborative Flashcard Editing** การแก้ไข Flashcards ร่วมกันแบบ Real-time ระหว่างผู้ใช้หลายคนจะยังไม่พัฒนาใน Term นี้

## 6. Risks & Assumptions

### Assumptions

1. ผู้ใช้มีเอกสารหรือ Lecture Notes ที่มีเนื้อหาเพียงพอสำหรับนำไปสร้าง Flashcards และต้องการลดเวลาในการสร้าง Flashcards ด้วยตนเอง
2. ผู้ใช้ยอมรับ Flashcards ที่ AI สร้างขึ้นหากสามารถตรวจสอบและแก้ไขเนื้อหาก่อนนำไปใช้ได้
3. การใช้ Spaced Repetition และการแสดงสถิติการเรียนจะช่วยให้ผู้ใช้สามารถทบทวนได้อย่างสม่ำเสมอและมีประสิทธิภาพมากขึ้น

### Risks

1. **AI สร้างเนื้อหาผิดหรือไม่ครบถ้วน** Flashcards ที่สร้างจากเอกสารอาจมีข้อมูลผิด ตีความคลาดเคลื่อน หรือขาดบริบท จึงต้องมี Flashcard Editor ให้ผู้ใช้ตรวจสอบและแก้ไขก่อนใช้งาน
2. **คุณภาพของเอกสารที่อัปโหลดแตกต่างกัน** เอกสารที่มีรูปแบบซับซ้อนหรือข้อมูลไม่ชัดเจนอาจทำให้ AI สร้าง Flashcards ได้ไม่ดี จึงต้อง validate รูปแบบและคุณภาพของ input
3. **ผู้ใช้อาจไม่ใช้ระบบอย่างต่อเนื่อง** แม้ระบบจะมี Spaced Repetition และ Statistics แต่ผู้ใช้อาจหยุดใช้งานก่อนเห็นประโยชน์ จึงควรติดตาม Streak และ Progress เพื่อช่วยสร้างแรงจูงใจ
4. **ต้นทุนและข้อจำกัดของ AI API** การสร้าง Flashcards ด้วย AI อาจมีค่าใช้จ่ายและข้อจำกัดด้าน API หรือจำนวน request จึงต้องควบคุมปริมาณการใช้งานและออกแบบการเรียก API อย่างเหมาะสม
