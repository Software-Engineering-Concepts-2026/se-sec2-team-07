# Main Scenario: สร้างแฟลชการ์ดอัตโนมัติเพื่อเตรียมสอบ

**Persona หลัก:** นิตยา "หนิง" ศรีสุข — นักศึกษาชั้นปีที่ 2 สาขาวิทยาการคอมพิวเตอร์

อีกสองวันจะสอบวิชา **Data Structures** แต่หนิงยังไม่ได้เริ่มทบทวนเนื้อหาอย่างจริงจัง เพราะช่วงสัปดาห์ที่ผ่านมาเธอต้องแบ่งเวลาไปทำงานพิเศษและเตรียมการแข่งขัน Hackathon ทำให้มีเพียงโน้ตที่จดไว้ระหว่างเรียนและไฟล์สไลด์ที่อาจารย์อัปโหลดไว้ในคอมพิวเตอร์เท่านั้น

เมื่อเปิดโปรแกรมแฟลชการ์ดที่เคยใช้อยู่ หนิงรู้สึกไม่อยากเริ่ม เพราะการสร้างแฟลชการ์ดด้วยตัวเองต้องใช้เวลานาน ทั้งการอ่านโน้ต คัดเลือกประเด็นสำคัญ และพิมพ์คำถาม–คำตอบทีละใบ ซึ่งมักใช้เวลากว่า 30 นาทีต่อหนึ่งบทเรียน ทำให้เธอมักเลือกอ่านโน้ตผ่าน ๆ แทน แม้จะรู้ว่าวิธีนี้ทำให้จำได้ไม่ดีนัก

หนิงจึงเปิดเว็บแอป **Smart Flashcards** ที่เพิ่งเริ่มใช้งาน เธออัปโหลดไฟล์สไลด์การสอนและโน้ตที่จดไว้ พร้อมเลือกหัวข้อ **Trees และ Graphs** ซึ่งเป็นเนื้อหาที่จะออกสอบ ระบบวิเคราะห์เอกสารด้วย AI และสร้างแฟลชการ์ดให้อัตโนมัติ โดยแบ่งเป็นคำถามเชิงแนวคิด คำถามเปรียบเทียบ และโจทย์ทบทวนความจำ

ก่อนบันทึก หนิงตรวจสอบแฟลชการ์ดที่ระบบสร้าง แก้ไขข้อความบางส่วนให้สั้นและเข้าใจง่ายขึ้น พร้อมลบคำถามที่ซ้ำกัน เมื่อพอใจแล้วจึงบันทึกชุดแฟลชการ์ดเข้าสู่คลังความรู้ของตนเอง

จากนั้นระบบจัดตารางทบทวนแบบ **Spaced Repetition** ให้โดยอัตโนมัติ พร้อมแนะนำว่าคืนนี้ควรทบทวนกี่ใบเพื่อให้พร้อมก่อนสอบ หนิงเริ่มตอบแฟลชการ์ดทันที และระบบบันทึกผลการตอบเพื่อปรับความถี่ในการทบทวนครั้งถัดไป

ภายในเวลาไม่ถึง **15 นาที** หนิงมีชุดแฟลชการ์ดคุณภาพสำหรับทบทวนครบทั้งบท โดยไม่ต้องเสียเวลาสร้างเองทีละใบ ทำให้เธอสามารถใช้เวลาที่เหลือไปฝึกทำโจทย์และเตรียมตัวสอบได้อย่างมั่นใจ

# โครงสร้างเรื่องเล่า (สำหรับอ้างอิงในทีม)

| องค์ประกอบ | รายละเอียด |

|------------|------------|

| **ฉากและตัวละคร** | หนิง นักศึกษาวิทยาการคอมพิวเตอร์ปี 2 ที่ต้องแบ่งเวลาระหว่างการเรียน งานพิเศษ และกิจกรรมของมหาวิทยาลัย กำลังเตรียมสอบวิชา Data Structures |

| **เป้าหมาย** | ต้องการสร้างแฟลชการ์ดสำหรับทบทวนเนื้อหาให้เร็วที่สุด เพื่อมีเวลาอ่านและฝึกทำโจทย์มากขึ้น |

| **อุปสรรค** | การสร้างแฟลชการ์ดด้วยตนเองใช้เวลานาน โน้ตมีหลายแหล่ง และการอ่านทบทวนแบบเดิมจำเนื้อหาได้ไม่ดี |

| **ลำดับเหตุการณ์กับระบบ** | อัปโหลดโน้ตและสไลด์ → เลือกหัวข้อ → AI สร้างแฟลชการ์ด → ตรวจสอบและแก้ไข → บันทึก → ระบบจัดตาราง Spaced Repetition → เริ่มทบทวน |

| **ผลลัพธ์** | ได้ชุดแฟลชการ์ดที่มีคุณภาพภายในเวลาอันสั้น พร้อมตารางทบทวนอัตโนมัติ ช่วยให้เตรียมสอบได้อย่างมีประสิทธิภาพโดยไม่ต้องเสียเวลาสร้างแฟลชการ์ดเอง |
