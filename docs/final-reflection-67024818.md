# Focus Flashcards – Reflection

## 1. What did you build?

ร่วมพัฒนาระบบ Focus Flashcards เว็บช่วยเรียนที่รองรับการสร้างการ์ดด้วยตนเองและใช้ AI สรุปเนื้อหาจากไฟล์/ข้อความ พร้อมโน้ต ตารางทบทวน และนาฬิกา Pomodoro

## 2. What problem did you solve?

ช่วยลดเวลาการจัดทำเนื้อหาทบทวนสอบที่กระจัดกระจาย โดยใช้ AI ช่วยเปลี่ยนสรุปเป็นบัตรคำคำศัพท์ให้ผู้ใช้ตรวจสอบ แก้ไข และจัดหมวดหมู่เข้าตารางเรียนได้อย่างเป็นระบบ

## 3. What technical decision are you proudest of?

การปรับโครงสร้าง Backend และการจัดการ API Route ให้เหมาะสมกับการรันบน Serverless/Vercel เพื่อลด Latency ในช่วง Cold Start และเพิ่มความเร็วในการตอบสนอง

## 4. What failure taught you the most?

ปัญหาการ Deploy ที่สถานะขึ้น Ready แต่ใช้งานไม่ได้จริงจากปัจจัยเรื่อง Environment, การสร้าง Build Files และการเชื่อมต่อฐานข้อมูล ทำให้เรียนรู้การวิเคราะห์ Logs อย่างเป็นระบบ

## 5. What would you do differently?

จะวางสถาปัตยกรรม Deployment และจัดการสภาพแวดล้อมระบบ ตั้งแต่สัปดาห์แรก โดยทดสอบ Deploy จากโปรเจกต์ขนาดเล็กก่อนเริ่มเพิ่มฟีเจอร์ซับซ้อน

## 6. How did you embody Tip 52 (Delight Users)?

ปรับปรุง UX จากข้อติชมจริง เช่น การเปิดให้แก้ไขการ์ดและโน้ตผ่าน Pop-up Modal โดยไม่ต้องสลับหน้า และออกแบบ Pomodoro Widget ให้ทำงานต่อเนื่องแม้ย่อหน้าต่าง

## 7. How did you embody Tip 53 (Sign Your Work)?

เขียน Commit Message ที่อธิบายความเปลี่ยนแปลงอย่างชัดเจน อ้างอิง Issue/Task เสมอ และจัดเตรียม Pull Request (PR) ที่มีคำอธิบายเหตุผลและวิธีทดสอบเพื่อให้เพื่อนในทีม Review ได้ง่าย

## 8. What value did this experience add to your SE journey?

เข้าใจวงจรการพัฒนาซอฟต์แวร์เต็มรูปแบบตั้งแต่ Requirements จนถึง Production และเปลี่ยนมุมมองจากการแก้ปัญหาเฉพาะหน้าไปสู่การตัดสินใจเชิงวิศวกรรมโดยอาศัยหลักฐานข้อมูล
