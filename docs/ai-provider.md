# AI ผ่าน KKU

โมเดลที่เลือกเมื่อ 2026-10-12: เปลี่ยนเป็น `gpt-5.4-mini` ตามคำขอของผู้ใช้
ใช้ API key เดิมของ KKU โดยไม่ย้าย key ไปยังผู้ให้บริการอื่น

```dotenv
OPENAI_MODEL=gpt-5.4-mini
OPENAI_BASE_URL=https://gen.ai.kku.ac.th/upacth/api/v1
OPENAI_API_MODE=chat
```

`OPENAI_API_KEY` เก็บใน `.env` ของเครื่องและ Environment Variables ของ Vercel
อย่าใส่ key ในโค้ด รายงาน หรือ commit

ระบบยังเรียก `POST /chat/completions` โดยใช้ชื่อโมเดลจากการตั้งค่า
จึงไม่ต้องเปลี่ยน SDK หรือ endpoint การสร้างการ์ดเมื่อเปลี่ยนโมเดล
ชุดทดสอบตรวจชื่อโมเดลและผล JSON ทั้งแบบตรงและมี code fence

การเปลี่ยนกลับเป็น `gpt-6-sol-pro` เมื่อ 2026-10-11 ตรวจด้วยชุดทดสอบจำลอง
เพราะโควตาหมดอยู่ในขณะนั้น ต่อมาผู้ใช้แจ้งว่าโควตากลับมาเมื่อ 2026-10-12
การเปลี่ยนโมเดลไม่ได้รีเซ็ตโควตา และอัตราหักโควตาของ KKU ต้องตรวจจากผู้ให้บริการ

การเปลี่ยนเป็น `gpt-5.4-mini` เมื่อ 2026-10-12 ผ่าน tests ที่เกี่ยวข้อง 29 รายการ
และเรียก KKU จริงด้วยตัวอย่าง Stack/Queue กับคำศัพท์อังกฤษ–ไทยที่ระดับกลาง
สร้างการ์ดได้ทั้งสองชุด โดยใช้ API key และ endpoint เดิม

หลังเปลี่ยนค่าในเครื่องให้ restart API หากกำลังรันอยู่
บน Vercel ต้อง deploy ใหม่จึงจะใช้ค่าใหม่ URL deployment เก่ายังใช้ค่าที่บันทึกตอน deploy เดิม
Preview และ Production ต้อง deploy สำหรับ environment ของตัวเอง

## การ์ดว่างหลังโควตากลับมา

ข้อความเรื่องเนื้อหาและระดับเกิดเมื่อผู้ให้บริการตอบสำเร็จ แต่ส่ง `{"cards":[]}`
ไม่ใช่ข้อความโควตาหมด ซึ่ง HTTP 429 จะแสดงแยกต่างหาก
Prompt รับรายการคำศัพท์ที่ไม่มีหัวตารางหรือเครื่องหมาย `:` และอธิบายว่าระดับกลาง
ใช้ความสัมพันธ์ที่ระบุไว้ในประโยคสั้น ๆ ได้ จำนวนที่เลือกเป็นจำนวนสูงสุด ไม่ต้องสร้างให้ครบ

หากผลลัพธ์ว่าง ระบบจะตรวจเนื้อหาซ้ำกับ AI อีกหนึ่งครั้ง โดยคงข้อความ ภาษา โมเดล
และระดับเดิม ทั้งสองครั้งใช้เวลารวมได้ไม่เกิน 90 วินาที และยังตรวจรูปแบบการ์ดตามเดิม
ไม่ลองซ้ำสำหรับโควตาหมด การปฏิเสธ หรือข้อมูลผิดรูปแบบ
หากยังว่าง ระบบแจ้งให้เพิ่มข้อเท็จจริง/ความหมาย เปลี่ยนระดับ หรือใช้โหมดแยกข้อความ
จึงไม่รับประกันว่าเนื้อหาทุกชนิดจะสร้างการ์ดได้ และการลองซ้ำอาจใช้โควตาเพิ่มหนึ่งคำขอ

เมื่อ 2026-10-12 ทดสอบ `gpt-6-sol-pro` ผ่าน KKU จริงที่ระดับกลาง ด้วยข้อความตัวอย่าง
Stack/Queue และคำศัพท์อังกฤษ–ไทย โดยสร้างการ์ดได้ทั้งสองชุด
ยังไม่มีข้อความต้นฉบับที่ผู้ใช้พบปัญหา จึงยังยืนยันสาเหตุของกรณีนั้นโดยตรงไม่ได้
