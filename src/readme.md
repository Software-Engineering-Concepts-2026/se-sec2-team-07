# Source Code

- `frontend/`: React + Vite + Plain CSS; components, pages, hooks and API client.
- `backend/`: Node.js + Express modular monolith; auth, decks, reviews, stats and generation modules.
- `backend/db/`: PostgreSQL connection pool, transactions and versioned SQL migrations.
- Automated tests are in root `tests/` (unit, integration, e2e).

See `docs/development.md` for setup and `docs/architecture/tech_stack.md` for the selected stack.
